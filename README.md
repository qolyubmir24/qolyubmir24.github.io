# Website Portofolio — Mirwan Qolyubi

Source code website portofolio pribadi yang di-host melalui GitHub Pages di **[qolyubmir24.github.io](https://qolyubmir24.github.io/)**.

## Bagian Halaman
- **Home** — Pengantar singkat dan tautan navigasi
- **About** — Profil singkat sebagai mahasiswa Informatika
- **Projects** — Daftar proyek pilihan
- **Skills** — Ringkasan kemampuan teknis
- **Contact** — Tautan kontak dan media sosial

## Struktur Berkas
```
.
├── index.html
├── styles.css
└── script.js
```

## Menjalankan Secara Lokal
Buka `index.html` langsung di browser atau jalankan server statis sederhana:

```bash
python -m http.server 8000
```
